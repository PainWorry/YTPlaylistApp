# Master Plan: YouTube Playlist App

## Objective
Build a functional Android application to search and play YouTube playlists, compiled via GitHub Actions to avoid local mobile hardware constraints.

## Technical Stack
- **Language:** Kotlin
- **Build System:** Gradle
- **Network:** Retrofit2 + Gson
- **UI:** XML Layouts, RecyclerView, WebView

## Execution Phases
1. Environment & Git Setup (Current)
2. Gradle & Android Manifest Scaffolding
3. UI Layout Construction
4. Kotlin Logic & API Integration
5. Cloud Compilation via GitHub Actions
